# SOP-MNT-009 Work Order Creation

## Purpose
Define how a maintenance work order is raised in SAP PM.

## Steps
1. Verify the asset tag in SAP PM.
2. Select the priority code.
3. Attach the request form FRM-MNT-221.
4. Submit the order to the planner queue.
